# Remuria

Halaman belajar teori musik interaktif di keyboard: interval, chord (lengkap dengan "rasa"-nya), tangga nada dan chord diatonik, progresi, chord dari suasana, latihan telinga, dan deteksi chord.

- Bisa dimainkan lewat klik, keyboard laptop, atau keyboard MIDI (Web MIDI; Chrome/Edge).
- Satu file statis: `index.html`.
